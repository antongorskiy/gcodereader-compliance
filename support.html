GCodeReader CNC Support

GCodeReader CNC previews CNC G-code, CAD exchange files and 3D models locally on your device.

Open a file

Tap the folder button inside the app and select a file from Files. For a cloud-backed file, first ensure it is downloaded and available locally.

Format compatibility

Common exchange formats include STEP, IGES, BREP, DXF, STL, OBJ and PLY. Native SLDPRT previews, Parasolid, DWG and CDR have limited coverage. Support depends on file version and available geometry; SLDASM assembly import is unavailable. If a file cannot be opened, export STEP, IGES, STL or DXF from its authoring application.

Contact support

Email rene.limberger@disney.com with the app version, device model, OS version, file format and a description of the issue. Please avoid sending confidential CAD or CNC files; a nonconfidential example or error message is usually enough to begin troubleshooting.

Privacy and licenses

Files are processed locally. Read the privacy policy and third-party license information. Build-specific library sources and relinking materials are available in the release archive.
